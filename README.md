Welcome to my personal portfolio website!

This project is part of my learning journey through **Dr. Angela Yu's Complete Web Development Bootcamp**. It showcases the HTML skills I have learned so far by bringing together my first web development projects.

## 🌐 About the Project

This is a beginner-friendly portfolio website built using HTML. It serves as a place to showcase my projects, introduce myself, and provide contact information.

## 📂 Projects Included

### 1. Movie and Anime Rankings

A webpage featuring my personal top 5 movies and anime, with descriptions and links to learn more.

### 2. Birthday Invitation

A fun birthday invitation webpage featuring:
